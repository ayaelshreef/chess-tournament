# School Chess Championship

Requires Node.js 20 or newer. From this folder, run `npm start`, then open [the tournament dashboard](http://127.0.0.1:3000). The project has no external dependencies.

Register students in Group A (grades 4–6) or Group B (grades 7–12). Generate a round, record each board’s result, and repeat for four rounds. If first place remains tied, record the group playoff winner. Use the Championship final tab once both finalists are confirmed.

- `frontend/` contains the dashboard, styling, and browser behavior.
- `backend/` serves the dashboard and calculates pairings, standings, and qualifiers.
- `data/tournament.json` is created on the first change. It holds student names and results. Copy this file to back up the tournament. Restore a backup with the server stopped, placing it at the same path.

Run a single server instance per tournament data file. The server listens on the local computer and is intended for one tournament desk.

Run `npm test` to verify tournament rules, API operations, and persistence.

## Publish on Cloudflare

Cloudflare Workers hosts the frontend and API. D1 stores the tournament. The browser will prompt for the username `organizer` and the password configured below.

1. From this project folder, run `npx wrangler@4 login` and sign in to Cloudflare.
2. Run `npx wrangler@4 d1 create school-chess-tournament`. Copy the database ID into `wrangler.toml`, replacing the all-zero placeholder.
3. Run `npx wrangler@4 d1 migrations apply DB --remote`.
4. Run `npx wrangler@4 deploy`. The app stays locked until you set a password.
5. Run `npx wrangler@4 secret put TOURNAMENT_PASSWORD`. Enter a long, unique password generated by a password manager. Open the HTTPS address printed by the deploy command and sign in.

Use `npx wrangler@4 deploy` for subsequent updates. The D1 database is separate from the Worker deployment. A new Cloudflare database starts empty. Any students and results previously saved in `data/tournament.json` stay on this computer unless you explicitly migrate them.
